AeroSaga: Temporal.io Autonomous Drone Mission Control

Project Overview

AeroSaga is a simulated autonomous drone mission control system developed using Java, Spring Boot, Temporal.io, and React.

Features

- Start drone missions
- Simulate drone takeoff and navigation
- Simulate package delivery
- Return drone to base
- Check mission status
- Abort mission

Technologies Used

- Java
- Spring Boot
- Temporal.io
- React
- Maven

Project Purpose

This project demonstrates workflow orchestration and autonomous drone mission simulation using Temporal.io.
